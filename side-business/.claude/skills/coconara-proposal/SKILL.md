# coconara 案件評估與提案

## 步驟

1. **整理需求**，存到 `leads/YYYYMMDD_案件名.md`：
   - 要做什麼 / 交付格式 / 期限 / 預算 / 修正次數 / 不明確的地方
2. **可行性判斷**（依使用者的語言回報）
   - 適合度：◎ / ○ / △ / ✕ 與原因
   - 預估工時（作業 ＋ 溝通 ＋ 修正緩衝 30%）
   - 換算時薪 = （預算 − 手續費）÷ 預估工時（手續費率請以 coconara 最新規定為準，查不到時標示「需確認」）
   - 風險：需求模糊、規格膨脹、著作權
   - **△ 以下建議不接，或列出要先問客戶的問題**
3. **撰寫提案（日文）**，存到 `proposals/`：
   - あいさつ（一句）
   - ご依頼内容の理解（用自己的話重述，讓客戶確認認知一致）
   - ご提案内容・進め方（步驟與里程碑）
   - 納期・お見積り（含修正次數、追加費用的條件）
   - 確認させていただきたい点（條列）
   - 締めのあいさつ
4. 長度控制在手機一個半畫面內，不寫空泛的自我推銷
5. 不誇大實績；只寫實際做過的技術
6. 交給使用者確認，**不要代為送出**。使用者是家人時，在 leads 檔加上「待 Maozai 確認」並寫進 `../TODO-review.md`
