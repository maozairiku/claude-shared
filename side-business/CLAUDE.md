# 副業工作區

## 定位
在 coconara 接小型案件（影片製作、簡單開發、Live2D / 建模、企劃提案書），用 Claude Code 提高效率。
**不接高難度或交期太緊的案件。** 正職優先。

## 資料夾
- `leads/`             — 候選案件（一案一檔：`YYYYMMDD_案件名.md`）
- `proposals/`         — 提案・報價文（日文）
- `projects/<案件名>/` — 進行中案件：`brief.md`（需求）、`log.md`（溝通紀錄）
  - 大型素材（影片、PSD 等）放雲端，這裡只放連結
- `templates/`         — 常用文案、報價表
- `done/`              — 結案紀錄（報價・實際工時・修正次數・學到的事）

## 判斷案件時要看
1. 技能是否能在預估工時內完成（UE5 / Unity / React / 企劃書 / 影片 / Live2D）
2. 換算時薪（含溝通與修正時間，扣除 coconara 手續費）
3. 需求是否模糊 → 模糊就列出要問客戶的問題，不要自己假設
4. 是否有著作權、保密、成果物使用範圍的問題

## 對外文章
- 日文商務敬語，親切但不過度謙卑
- 不承諾做不到的交期或品質；寫清楚修正次數、交付格式、著作權歸屬
- 草稿交給使用者確認，**絕對不要直接送出**
- 不寫本名、聯絡方式（coconara 規約也禁止站外聯絡）
