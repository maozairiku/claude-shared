# 進場・離場分析

定位與禁止事項以 `CLAUDE.md` 為準：這是**條件分析**，不是買賣指示。

## 步驟

1. **確認對象**：市場與代號（例：`7974.T`、`AAPL`、`2330.TW`）、使用者的帳戶（Maozai / 家人）、預計持有期間
2. **收集最新資料**（WebSearch，依 `reference/sources.md`，每個數字附出處・日期）
   - 股價、52 週高低、50 日・200 日移動平均
   - PER・PBR・殖利率：現在 vs 過去 5 年區間 vs 同業 2–3 家
   - 最近一期財報與公司指引、下一次財報日、除權息日
   - **分析師共識**：評等分布、平均・最高・最低目標價、分析師人數 — **至少 2 個來源**
   - 最近 3 個月的重要事件
3. **估值區間**：用 (a) 歷史 PER 區間 (b) 分析師目標價 (c) 同業比較，算出「偏低 / 合理 / 偏高」的價格區間，寫出計算過程
4. **技術面參考**：近期的支撐・壓力（近期高低點、移動平均）— 標示「僅供參考」
5. **情境表**

   | 情境 | 價格區間 | 需要發生的條件 |
   |---|---|---|
   | 樂觀 | | |
   | 基準 | | |
   | 悲觀 | | |

   不要寫出沒有根據的機率數字
6. **進場條件檢查**：對照 `CLAUDE.md` 的使用者規則（集中度、停損、不碰的東西），逐條 ✅ / ❌；並說明現價在估值區間的哪個位置
7. **離場參考**（三種一起列）
   - 獲利了結的參考價：基準情境上緣、分析師平均目標價
   - 停損的參考價：使用者規則（例：−15%）、重要支撐跌破
   - 重新檢討的觸發條件：財報不如預期、指引下修、論點不成立時
8. **匯率**：非日圓資產要寫出匯率變動的影響
9. **輸出**（手機一個半畫面內）
   - 結論先寫：「依你的規則，進場條件 ○ 項符合 / ○ 項不符合；現價位於估值區間的 ○○」
   - 情境表、離場參考、主要風險 3 點
   - 「查不到 / 未確認」的項目
   - 最後一行：「以上是條件分析，最後判斷請自行決定。」
10. 存到 `notes/<代號>-analysis-YYYYMMDD.md`（寫上執行者）
11. 使用者決定買賣時，提醒把**當時的理由與停損價**寫進 `journal/YYYY-MM.md`
