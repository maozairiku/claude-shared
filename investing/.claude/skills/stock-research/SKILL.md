# 個股・ETF 研究

## 步驟

1. **一律先 WebSearch**（公司 IR、決算短信、EDINET / SEC、交易所、主要新聞），記下每個數字的出處與日期
2. 整理到 `notes/<代號>.md`，固定格式：

   ```
   # <名稱>（<代號>） — 更新：YYYY-MM-DD / 更新者：<名字>
   ## 一句話：靠什麼賺錢
   ## 最新數據（附出處・日期）
   - 股價 / 時價總額 / PER / PBR / 配息殖利率
   - 最近一期營收・營業利益的年增率
   - 公司自己的業績預估 vs 實績
   ## 最近 3 個月的重要事件
   ## 看多的理由（他人實際的論點）
   ## 看空的理由・風險（他人實際的論點）
   ## 和我們的前提對照（CLAUDE.md 的規則是否符合）
   ## 還不知道、應該確認的事
   ```

3. 回報重點（手機一個畫面內），**看多與看空同等份量**
4. 查不到或資料過舊的欄位寫「未確認」，不推測補上
5. 結尾不寫買賣建議，改寫「若要判斷，接下來值得看的指標是…」
