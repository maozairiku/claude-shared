# 持股與交易檢討

## 步驟

1. 讀取 `portfolio.md`、`watchlist.md`、本月與上月的 `journal/`
2. 確認要檢討誰的帳戶（Maozai / 家人 / 兩者），不要混在一起計算
3. **配置檢查**：個股集中度、產業集中度、日本 / 美國 / 現金比例，是否違反 CLAUDE.md 的風險規則
4. **持股近況**：每檔用 WebSearch 確認近一個月的重要新聞（決算、指引變更、重大事件），一檔一行，附出處
5. **交易回顧**：本月每筆交易
   - 當時寫下的理由，現在是否仍成立
   - 是否有常見偏誤：追高、攤平虧損、過早獲利了結、沒有理由的交易
6. **NISA 額度**（有記錄的話）：今年已用 / 剩餘
7. 回報格式：
   - 需要注意的 1–3 件事（先講）
   - 配置表
   - 交易回顧
   - 下個月要確認的事
8. 把摘要追加到 `journal/YYYY-MM.md` 的「月度檢討」段落，並寫上執行者

## 注意
- 不給買賣斷定建議；指出事實與自己訂的規則之間的落差
