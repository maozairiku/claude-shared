# 資訊來源與可信度

## 可信度的順序（高 → 低）
1. **官方一次資料**：公司 IR、法定揭露（決算短信、有價證券報告書、10-K / 10-Q、財報）
2. **交易所・官方機構的資料**
3. **整理一次資料的資料網站**（數字要和一次資料對照）
4. **主要媒體的新聞**
5. **分析師的評等・目標價**（他人的意見；標示來源、日期、人數）
- **不採用**：社群媒體、論壇、匿名部落格、「飆股推薦」類網站

## 日本株
- 一次資料：TDnet（適時開示）、EDINET（有價證券報告書）、各公司 IR
- 資料網站：株探（kabutan）、IRBANK、Yahoo!ファイナンス、会社四季報オンライン
- 分析師共識：みんかぶ、各證券公司的レポート
- 新聞：日本経済新聞

## 米国株
- 一次資料：SEC EDGAR（10-K / 10-Q / 8-K）、各公司 IR、決算說明會（earnings call）
- 資料網站：Yahoo Finance、Nasdaq.com
- 分析師共識：Yahoo Finance、MarketBeat、TipRanks（附人數與日期）
- 新聞：Reuters、Bloomberg、WSJ、CNBC

## 台灣股
- 一次資料：公開資訊觀測站（MOPS）、臺灣證券交易所（TWSE）、證券櫃檯買賣中心（TPEx）、各公司 IR・法說會
- 資料網站：Goodinfo! 台灣股市資訊網、財報狗
- 新聞：鉅亨網、經濟日報、工商時報

> 網站可能需要登入或付費，取不到時改用其他來源，並在分析中寫明「未確認」。
